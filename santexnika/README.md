# Дом Сантехники · Балаково

Готовый адаптивный лендинг магазина: каталог с ценами из открытой витрины, акции и преимущества, новости, контакты с двумя адресами и картой, форма обратного звонка, SEO-файлы и отдельная панель управления. Проект без npm-зависимостей: статические страницы и небольшой Node.js сервер.

## Быстрый запуск

Требуется Node.js 18.17+.

```bash
cp .env.example .env
# обязательно задайте собственный длинный ADMIN_PASSWORD
npm start
```

Откройте `http://localhost:3000`. Сервер привязывается к `0.0.0.0` — подходит для reverse proxy и live preview.

## Управление новостями

1. Задайте `ADMIN_PASSWORD` в `.env` и перезапустите сервер.
2. Откройте `/admin`.
3. В панели можно синхронизировать стену VK вручную, скрывать и закреплять публикации, править заголовок и текст, удалять и создавать новости.
4. Для автоматического импорта заполните `VK_ACCESS_TOKEN`. Сервер запускает синхронизацию при старте и далее с интервалом `VK_SYNC_INTERVAL_MINUTES` (по умолчанию 30 минут).
5. Группа указана как `VK_GROUP_ID=223639597`, короткий адрес — `houseplumbers`. Перед публикацией проверьте ID/права доступа токена у владельца сообщества.

В импортере есть список включающих ключей `VK_INCLUDE_KEYWORDS` и исключающих `VK_EXCLUDE_KEYWORDS`. По умолчанию включены сантехника, мебель для ванной, ванны, смесители, душевые, скидки, доставка, акции, поступления и близкие категории. Новые посты без совпадений не публикуются автоматически. Импортированная запись сначала доступна в панели, откуда её можно отредактировать, скрыть или удалить.

В `data/news.json` лежит стартовая витрина из публично индексируемых публикаций. До добавления токена она показывается как предварительно загруженный контент; это не live-синхронизация.

## Заявки в Telegram и MAX

Форма отправляет заявку на сервер. Сервер сохраняет её в закрытый файл `data/leads.json` и параллельно отправляет уведомления в настроенные мессенджеры. Токены не передаются в браузер.

Заполните в `.env`:

```dotenv
TELEGRAM_BOT_TOKEN=...
TELEGRAM_CHAT_ID=...
MAX_BOT_TOKEN=...
MAX_CHAT_ID=...
```

- Telegram: создайте бота в `@BotFather`, добавьте бота в рабочий чат и получите `chat_id`.
- MAX: создайте и настройте бота в кабинете разработчика MAX, после публикации/получения токена укажите токен и `chat_id`, доступный боту. Инструкция: <https://dev.max.ru/docs/chatbots/bots-coding/prepare>.
- На сервере должна быть доступна исходящая HTTPS-связь с Bot API. После изменения `.env` перезапустите приложение.

Если токены пока не заданы, заявки принимаются и сохраняются в `data/leads.json`, но внешние уведомления не отправляются. Файл с заявками исключён из раздачи сайтом и добавлен в `.gitignore`; храните его на сервере с ограниченным доступом и удаляйте по утверждённому сроку хранения.

## Перед публикацией в интернете

- Укажите постоянный HTTPS-домен и обновите его в `index.html` (canonical, Open Graph, JSON-LD), `robots.txt` и `sitemap.xml`. Сейчас подготовлен домен `domsantehniki64.ru` как найденный публичный адрес магазина.
- Задайте уникальный `ADMIN_PASSWORD`; не оставляйте значение-заглушку из `.env.example`.
- Укажите VK-токен, токены Telegram и MAX и реальные ID получателей. Проверьте тестовой заявкой, что каждое уведомление доходит.
- Проверьте карточки магазинов, режим работы, карту, акции и текущие цены; добавьте настоящие публичные соцссылки, если у магазина есть Telegram/MAX-аккаунты.
- В подвале и форме оставлена запрошенная ссылка на `https://tatisweb.github.io/politica.html`. Сейчас это политика разработчика сайта, а не подтверждённая политика оператора магазина. До приёма реальных персональных данных замените её на документ магазина/оператора и заполните реквизиты, цели, сроки хранения и порядок отзыва согласия. Это важно для корректной обработки заявок.
- Разметка не содержит выдуманных рейтингов/звёзд. Google и Яндекс могут показывать звёздный сниппет только при наличии подходящих подтверждённых отзывов и валидной разметки; добавлять фиктивные оценки нельзя.
- Добавьте сайт в Яндекс Вебмастер и Google Search Console, подтвердите домен, отправьте `https://ВАШ-ДОМЕН/sitemap.xml`; настройте Яндекс Метрику/Google Analytics только после получения счётчиков и соблюдения требований к согласию.

## Структура

- `index.html`, `styles.css`, `app.js` — основная страница и интерактивность.
- `server.js` — раздача сайта и API заявок, VK-импорт, API панели управления.
- `admin.html`, `admin.css`, `admin.js` — защищённая панель `/admin`.
- `data/products.json`, `data/news.json` — каталог и новостная витрина.
- `assets/` — локальные изображения; `og-image.jpg` — карточка Open Graph.
- `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `site.webmanifest` — иконки устройств.
- `robots.txt`, `sitemap.xml`, `404.html`, `.htaccess` — базовые файлы SEO и веб-сервера.
